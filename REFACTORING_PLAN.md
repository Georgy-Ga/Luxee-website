## ⚠️ Важные правила

1. **Не ломать функциональность** - тестировать после каждого изменения
2. **Сохранять экспорты** - старые импорты должны работать через index.js
3. **Логическая группировка** - файлы группируются по функциональности
4. **Документация** - добавлять комментарии к новым модулям
5. **Постепенность** - рефакторить по одному файлу за раз
