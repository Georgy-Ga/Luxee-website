# Обзор проекта Luxee Bot

## Описание
Luxee Bot - это автоматизированное приложение для массовой рассылки сообщений на платформе luxee.io. Приложение построено на Python с использованием Tkinter для GUI и Selenium для автоматизации браузера.

## Основная функциональность
- Автоматический вход на сайт luxee.io
- Управление несколькими профилями
- Массовая рассылка сообщений в чаты
- Массовая рассылка писем (mail)
- Фильтрация клиентов по различным параметрам
- Отслеживание статуса рассылок
- Защита от блокировки (задержки между сообщениями)

## Технологический стек
- **Python 3.x**
- **RPA Framework** (rpaframework==30.0.2) - для автоматизации браузера
- **Tkinter** - для графического интерфейса
- **BeautifulSoup4** - для парсинга HTML
- **Requests** - для HTTP запросов
- **Cryptography** - для шифрования учетных данных

## Основные компоненты

### 1. Точка входа (main.py)
Запускает приложение через класс `App`.

### 2. Конфигурация (config.py)
Содержит глобальные настройки:
- `SKIP_SENDING_MESSAGE` - режим отладки (не отправлять сообщения)
- `HIDDEN_BROWSER` - скрытый режим браузера
- `WAIT_MINUTES_BETWEEN_PROFILES` - задержка между профилями

### 3. Модели данных (src/models.py)
- **Profile** - профиль на luxee.io
- **Client** - клиент для рассылки
- **Message** - сообщение в чат
- **MailMessage** - письмо (mail)
- **Distribution** - конфигурация рассылки

### 4. Автоматизация браузера (src/luxee_site/luxee_browser.py)
Класс `Luxee` управляет всеми операциями в браузере:
- Вход на сайт
- Получение списка профилей
- Получение списка клиентов
- Отправка сообщений
- Отправка писем

### 5. HTTP запросы (src/luxee_site/luxee_requests.py)
Класс `LuxeeRequests` выполняет API запросы:
- Получение профилей
- Получение настроек профиля
- Получение списка клиентов
- Проверка доступности профиля для клиента

### 6. GUI (src/application/)
Tkinter интерфейс с несколькими окнами и фреймами для управления рассылками.

## Процесс работы

1. **Вход в систему**
   - Пользователь вводит логин/пароль
   - Данные шифруются и сохраняются
   - Выполняется вход на luxee.io

2. **Загрузка профилей**
   - Получение списка доступных профилей
   - Отображение в GUI

3. **Настройка рассылки**
   - Выбор профиля
   - Настройка фильтров (платные/бесплатные, пустые/непустые чаты)
   - Создание сообщений или писем
   - Установка лимитов

4. **Выполнение рассылки**
   - Фильтрация клиентов
   - Проверка доступности профиля для клиента
   - Переход в чат/mail
   - Отправка сообщений
   - Задержки между отправками

5. **Отчет**
   - Количество отправленных сообщений
   - Количество пропущенных клиентов
   - Причины остановки

## Безопасность

- Учетные данные шифруются с помощью Fernet (cryptography)
- Проверка доступности username через Google Sheets
- Защита от одновременного использования одного username
- Сохранение ошибок с скриншотами и HTML страниц

## Обработка ошибок

При возникновении ошибок Selenium:
- Создается папка в `lexee_errors/` с timestamp
- Сохраняется скриншот
- Сохраняется HTML страницы
- Сохраняется traceback
- Сохраняются последние логи

## Особенности

- Автоматический повторный вход при сбоях
- Естественный ввод текста (имитация человека)

- Поддержка русской раскладки клавиатуры (Ctrl+C/V/X)
