# Функция "Отправлять конкретным пользователям"

## Описание

Добавлена новая функция для отправки сообщений конкретным пользователям по их ID. Это позволяет отправлять сообщения целевой аудитории без необходимости фильтрации по типу пользователя (Оплаченный/Бесплатный).

## Как использовать

### 1. Выбор типа пользователя

В разделе **"Тип пользователя"** теперь доступен 4-й вариант:
- Оплаченный
- Бесплатный
- Все
- **Отправлять конкретным пользователям** ← НОВОЕ

### 2. Ввод списка ID

При выборе опции "Отправлять конкретным пользователям" появляется дополнительное поле:

```
Список пользователей для отправки (через запятую):
[текстовое поле]
```

**Пример ввода:**
```
1454399, 1609606, 1637656, 154100
```

### 3. Исключения

Если ID пользователя указан **И** в списке для отправки, **И** в списке исключений - сообщение **НЕ** будет отправлено этому пользователю.

**Пример:**
- Список для отправки: `1454399, 1609606, 1637656`
- Исключения: `1609606`
- Результат: Сообщения будут отправлены только `1454399` и `1637656`

## Технические детали

### Формирование URL

#### Для Chat:
```
https://luxee.io/chats/?ownerUid={ownerUid}&profileUid={profileUid}&userUid={userUid}
```

#### Для Mail:
```
https://luxee.io/communication/mail/?ownerUid={ownerUid}&userUid={userUid}
```

Где:
- `ownerUid` - ID выбранного профиля (анкеты)
- `profileUid` - динамический ID профиля для клиента (получается из API)
- `userUid` - ID пользователя из списка

### Retry логика

Для конкретных пользователей реализована **3-кратная** попытка отправки:

1. **Попытка 1**: Отправка сообщения
2. **Попытка 2**: Если не удалось - повтор через 3 секунды
3. **Попытка 3**: Если снова не удалось - последняя попытка через 3 секунды
4. **Результат**: Если все 3 попытки неудачны - пользователь пропускается

### Фильтры

При использовании режима "Отправлять конкретным пользователям":

✅ **Применяются:**
- Фильтр "Отправлять только если" (Не отправляли ранее / Уже отправляли / Отправлять всем)
- Исключения по ID
- Проверка доступности профиля для пользователя

❌ **НЕ применяются:**
- Фильтрация по приложениям (Tinder, Bumble и т.д.)
- Фильтрация по типу пользователя (Оплаченный/Бесплатный)

## Примеры использования

### Пример 1: Отправка конкретным клиентам

**Настройки:**
- Тип пользователя: `Отправлять конкретным пользователям`
- Список пользователей: `1454399, 1609606, 1637656`
- Исключения: (пусто)
- Лимит: `3`

**Результат:** Сообщения будут отправлены всем трем пользователям.

### Пример 2: С исключениями

**Настройки:**
- Тип пользователя: `Отправлять конкретным пользователям`
- Список пользователей: `1454399, 1609606, 1637656, 154100`
- Исключения: `1609606, 154100`
- Лимит: `4`

**Результат:** Сообщения будут отправлены только `1454399` и `1637656`.

### Пример 3: Mail рассылка

**Настройки:**
- Тип сообщения: `Mail`
- Тип пользователя: `Отправлять конкретным пользователям`
- Список пользователей: `1454399, 1609606`
- Лимит: `2`

**Результат:** Mail будет отправлен обоим пользователям с 3 попытками для каждого.

2. `src/application/distribution_settings_frame.py` - добавлена UI для нового функционала

4. `src/luxee_site/luxee_browser.py` - реализована логика отправки конкретным пользователям с retry

## Важные замечания

⚠️ **Внимание:**
- ID пользователей должны быть числами, разделенными запятыми
- Пробелы вокруг ID игнорируются
- Если профиль недоступен для пользователя - он будет пропущен
- Retry логика (3 попытки) работает только для конкретных пользователей
- Для обычной рассылки (Оплаченный/Бесплатный/Все) retry логика не применяется
