## Основные концепции

### Профили (Profiles)
Профили - это анкеты на luxee.io, от имени которых отправляются сообщения.
- Имеют статический `owner_uid` (import_uid)
- Имеют динамический `uid` (profileUid) для каждого клиента
- Могут быть активными или отключенными
- Связаны с приложениями (Tinder, Badoo и т.д.)

### Клиенты (Clients)
Клиенты - это получатели сообщений.
- Имеют уникальный `uid` (userUid)
- Фильтруются по различным параметрам
- Могут быть платными или бесплатными
- Связаны с конкретными приложениями

### Рассылки (Distributions)
Рассылки - это конфигурации для массовой отправки сообщений.
- Связаны с одним профилем
- Содержат фильтры клиентов
- Имеют лимиты и ограничения
- Могут быть для чатов или писем (mail)

## Важные замечания

### URL параметры
⚠️ **Критически важно понимать разницу между ownerUid и profileUid!**

- `ownerUid` - это статический ID профиля (не меняется)
- `profileUid` - это динамический ID (получается для каждого клиента через API)
- Перед отправкой сообщения ОБЯЗАТЕЛЬНО нужно получить `profileUid` через API

Подробнее: [URL_PARAMETERS_ANALYSIS.md](URL_PARAMETERS_ANALYSIS.md)

### Безопасность
- Учетные данные шифруются
- Username проверяется через Google Sheets
- Защита от одновременного использования одного username
- Задержки для защиты от блокировки

### Обработка ошибок
- Автоматический повторный вход при сбоях (до 3 попыток)
- Сохранение скриншотов и HTML при ошибках
- Логирование всех операций

## Структура данных

### Profile.owner_uid vs Profile.uid

```python
# При загрузке профилей
profile = Profile(...)
profile.owner_uid = 607823  # Статический ID из HTML
profile.uid = None          # Пока не заполнен

# При проверке доступности для клиента
_is_profile_available_for_user(client.uid, profile)
# API запрос возвращает: {"data": [{"import_uid": 607823, "uid": 1609606}]}
profile.uid = 1609606       # Динамический ID для этого клиента

# При формировании URL
url = f"https://luxee.io/chats/?ownerUid={profile.owner_uid}&profileUid={profile.uid}&userUid={client.uid}"
# Результат: https://luxee.io/chats/?ownerUid=607823&profileUid=1609606&userUid=1454399
```
