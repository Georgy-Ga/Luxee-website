# Инструкция по сборке EXE файла

## Способ 1: Автоматическая сборка (Рекомендуется)

Просто запустите:
```bash
python build_exe.py
```

Скрипт автоматически:
- Установит PyInstaller (если не установлен)
- Соберет EXE файл
- Сохранит результат в папку `dist/`

## Способ 2: Ручная сборка

### Шаг 1: Установите PyInstaller
```bash
pip install pyinstaller
```

### Шаг 2: Соберите EXE
```bash
pyinstaller LuxeeBot.spec
```

## Результат

После успешной сборки:
- **EXE файл:** `dist/LuxeeBot.exe`
- **Размер:** ~50-100 MB (включает все зависимости)
- **Запуск:** Двойной клик по `LuxeeBot.exe`

## Что включено в EXE:

✅ Все функции программы
✅ Все библиотеки (Selenium, RPA, BeautifulSoup, и т.д.)
✅ Иконка приложения
✅ GUI интерфейс
✅ Функция "Отправлять конкретным пользователям"
✅ Retry логика (3 попытки)
✅ Все исправления и улучшения

## Важно:

⚠️ **Chrome/Chromium** должен быть установлен на компьютере где запускается EXE
⚠️ **Интернет соединение** требуется для работы
⚠️ **Антивирус** может блокировать - добавьте в исключения

## Распространение:

Вы можете скопировать `dist/LuxeeBot.exe` на любой компьютер с Windows и запустить без установки Python!

## Troubleshooting:

### Ошибка при сборке:
- Убедитесь что все зависимости установлены: `pip install -r requirements.txt`
- Попробуйте обновить PyInstaller: `pip install --upgrade pyinstaller`

### EXE не запускается:
- Проверьте антивирус
- Запустите от имени администратора
- Проверьте что Chrome установлен

### Большой размер файла:
- Это нормально, EXE включает все библиотеки
- Можно уменьшить используя `--onedir` вместо `--onefile` в spec файле
