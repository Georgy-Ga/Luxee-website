## 🔄 Архитектура данных

### Flow создания рассылки:
```
1. Пользователь заполняет форму → addToQueue()
2. Рассылка добавляется в локальную очередь
3. Кнопка "Начать рассылку" → distributionApi.create()
4. Backend создаёт Distribution в MongoDB
5. Backend запускает Python spambot
6. Python отправляет webhooks → Node.js
7. Node.js emit WebSocket events
8. Frontend получает события → updateProgress()
```

### WebSocket синхронизация:
```
Python DistributionManager
    ↓ HTTP POST webhook
Node.js distributionWebhookController
    ↓ MongoDB update
    ↓ io.emit('distribution:progress')
Frontend useDistributionSync
    ↓ updateProgress()
Store + UI обновление
```
