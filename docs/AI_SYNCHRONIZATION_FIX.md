## Архитектура AI управления

### Backend (✅ Работает правильно)

#### Эндпоинты API:
```
GET  /ai/my-status                      - Получить свой AI статус
POST /ai/my-toggle                      - Переключить свой AI (пользователь)
GET  /ai/my-accounts                    - Получить AI статусы своих аккаунтов
POST /ai/my-accounts/:accountId/toggle  - Переключить AI своего аккаунта

GET  /ai/users                          - Получить всех пользователей (admin)
POST /ai/users/:userId/set              - Установить AI пользователя (admin)
POST /ai/users/:userId/set-all-accounts - Установить AI всех аккаунтов (admin)
GET  /ai/accounts                       - Получить все аккаунты (admin)
POST /ai/accounts/:accountId/set        - Установить AI аккаунта (admin)
```

#### Логика разрешений:
1. **Глобальный AI пользователя** (`user.aiEnabled`):
   - Админ может включать/выключать через Header или AdminModal
   - Пользователь может только выключить (не может включить)

2. **AI управление админом** (`user.aiEnabledByAdmin`):
   - Только админ может устанавливать через AdminModal/AiTab
   - Это "мастер-переключатель" для пользователя

3. **AI аккаунта** (`account.aiEnabled` + `account.aiEnabledByAdmin`):
   - `aiEnabledByAdmin` - устанавливает только админ
   - `aiEnabled` - может переключать пользователь (только выключить)
   - AI аккаунта работает только если: `user.aiEnabled && user.aiEnabledByAdmin && account.aiEnabled && account.aiEnabledByAdmin`

### Frontend

#### Компоненты управления AI:

1. **Header.jsx** (главное окно):
   - Кнопка `AI: ON/OFF` - глобальное управление AI пользователя
   - Доступна всем пользователям
   - Админ может включать/выключать свободно
   - Обычный пользователь может только выключить

2. **Sidebar.jsx** (левая панель с аккаунтами):
   - Маленькие кнопки `AI` для каждого Luxee аккаунта
   - Зелёная = включен, красная = выключен
   - Пользователь может переключать AI своих аккаунтов
   - Синхронизируется с backend через `aiApi.toggleMyAccountAi()`

3. **AdminModal/AiTab.jsx** (настройки → AI управление):
   - Доступно только админам
   - Показывает всех пользователей и их аккаунты
   - Админ может:
     - Включать/выключать глобальный AI пользователя
     - Включать/выключать AI для всех аккаунтов сразу
     - Включать/выключать AI для отдельных аккаунтов

#### Store (chatStore.js):


## Как работает синхронизация

### При логине (App.jsx):
1. Получаем данные пользователя: `authApi.getCurrentUser()`
2. Устанавливаем AI статус: `setAIStatus(user.aiEnabled, user.aiEnabledByAdmin)`
3. Загружаем AI статусы аккаунтов: `loadAccountAIStatuses()`

### При переключении в Header:
1. Пользователь кликает кнопку `AI: ON/OFF`
2. Проверяются разрешения (админ или нет)
3. Вызывается `aiApi.toggleMyAi(newState)`
4. Обновляется локальное состояние: `toggleAI()`

### При переключении в Sidebar:
1. Пользователь кликает кнопку `AI` на аккаунте
2. Вызывается `toggleAIForAccount(accountId)`
3. Внутри: `await aiApi.toggleMyAccountAi(accountId)`
4. Обновляется локальное состояние автоматически

### При изменении админом в AdminModal:
1. Админ переключает AI через AiTab
2. Вызывается соответствующий admin API
3. После успешного вызова: `await loadData()` - перезагружает все данные
4. ⚠️ **ВАЖНО**: Изменения не отражаются автоматически в Header/Sidebar других пользователей
5. **Решение**: Нужен WebSocket или периодический refetch для синхронизации

## Оставшиеся улучшения (опционально)

### 1. Реалтайм синхронизация
**Проблема**: Если админ меняет AI статус через AdminModal, это не отражается в реальном времени у пользователя в Header/Sidebar

**Решение**:
- Вариант A: WebSocket для push обновлений
- Вариант B: Polling - периодический refetch каждые 30-60 сек
- Вариант C: Event bus через BroadcastChannel API (только один браузер)

### 2. Индикатор загрузки
**Текущее**: Кнопка AI переключается моментально
**Улучшение**: Показывать spinner во время API вызова

Пример:
```jsx
const [isTogglingAI, setIsTogglingAI] = useState(false);

const handleAIToggle = async () => {
  setIsTogglingAI(true);
  try {
    await aiApi.toggleMyAi(!aiEnabled);
    toggleAI();
  } finally {
    setIsTogglingAI(false);
  }
};

// В JSX:
{isTogglingAI ? '⏳' : aiEnabled ? '🤖' : '🚫'}
```

### 3. Оптимистичные обновления
**Текущее**: Обновляем UI после успешного API ответа
**Улучшение**: Обновляем UI сразу, откатываем при ошибке

```javascript
const handleAIToggle = async () => {
  const oldState = aiEnabled;
  toggleAI(); // Оптимистично меняем
  
  try {
    await aiApi.toggleMyAi(!oldState);
  } catch (error) {
    toggleAI(); // Откатываем при ошибке
    alert('Ошибка');
  }
};
```

### 4. Создание reusable компонентов
Сейчас кнопки AI дублируются. Можно создать:

**`components/AIToggleButton.jsx`**:
