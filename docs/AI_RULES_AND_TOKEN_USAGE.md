## 💰 Расчет использования токенов

### Структура запроса к AI

Каждый запрос содержит:
1. **System Prompt** (правила поведения)
2. **User Message** (контекст профиля + сообщение мужчины)
3. **AI Response** (генерируемый ответ)

### Подсчет токенов

#### 1. System Prompt (правила)
```
Текст: ~2,100 символов (на английском) - обновлено с новыми правилами
Токены: ~520-550 токенов
```

**Расчет**: Примерно 1 токен = 4 символа для английского текста

**System Prompt включает**:
- Роль и задача: ~100 токенов
- 19 правил сайта: ~250 токенов
- Стиль общения: ~100 токенов

#### 2. User Message (профиль + сообщение)
```javascript
// Пример запроса
{
  "role": "user",
  "content": `Profile: Anna, 25, Ukraine, Kyiv
Man's message: "Hey beautiful! How was your day?"
Generate response.`
}
```

**Токены**: ~30-50 токенов (зависит от длины сообщения мужчины)

- Информация о профиле: ~15 токенов
- Сообщение мужчины: ~15-30 токенов (обычно короткие)
- Инструкция: ~5 токенов

#### 3. AI Response (ответ)
```
Max tokens: 150
Реальный размер: обычно 20-50 токенов
```

Короткие ответы (1-3 предложения) занимают **30-50 токенов**

## ⚡ Оптимизация токенов

### Текущие настройки
- ✅ `max_tokens: 150` - ограничивает длину ответа
- ✅ Короткие сообщения (1-3 предложения)
- ✅ Нет истории переписки (только последнее сообщение)

### Возможная оптимизация
1. **Сократить System Prompt** (если нужно):
   - Объединить похожие правила
   - Убрать избыточные объяснения
   - **Экономия**: ~100-150 токенов (20-30%)

2. **Уменьшить max_tokens** до 100:
   - Ответы всё равно короткие
   - **Экономия**: потенциально меньше output токенов

3. **Кэширование System Prompt** (DeepSeek Prompt Caching):
   - System Prompt кэшируется на стороне API
   - **Экономия**: до 90% на input токенах при повторных запросах
   - Нужно проверить поддержку в DeepSeek
