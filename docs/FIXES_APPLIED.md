### 1. ✅ Race Conditions в Request Queue Service (ИСПРАВЛЕНО)

**Файл**: `backend/src/services/browser/requestQueueService.js`

**Проблема**: Между проверкой блокировки и её установкой мог пройти другой запрос, что приводило к race conditions.

**Решение**: Реализован Promise Chain для атомарных операций.

**Изменения**:
```javascript
// БЫЛО (с race condition):
while (this.locks.get(accountId)) {
    await this.queues.get(accountId);
    await new Promise(resolve => setTimeout(resolve, 100));
}
this.locks.set(accountId, true); // ⚠️ Не атомарно!

// СТАЛО (атомарно):
const currentQueue = this.queues.get(accountId) || Promise.resolve();
const newQueue = currentQueue.then(async () => {
    const result = await fn();
    return result;
});
this.queues.set(accountId, newQueue);
return newQueue;
```

**Результат**:
- ✅ Удалена Map `locks` (источник race condition)
- ✅ Запросы выполняются строго последовательно
- ✅ Атомарная операция через цепочку промисов
- ✅ Упрощена логика без потери функциональности

### 2. ✅ Memory Leak в Browser Contexts (ИСПРАВЛЕНО)

**Файл**: `backend/src/services/browser/browserService.js`

**Проблема**: Контексты браузера никогда не удалялись автоматически. При 200-300 аккаунтах это приводило к 20-60GB использования памяти.

**Решение**: Реализован TTL (Time To Live) с автоматической очисткой неактивных контекстов.

**Изменения**:
```javascript
// Добавлено отслеживание активности
const contextLastActivity = new Map();
const CONTEXT_TTL = 30 * 60 * 1000; // 30 минут
const CLEANUP_INTERVAL = 5 * 60 * 1000; // 5 минут

// Новые методы:
- cleanupInactiveContexts() - очистка неактивных контекстов
- startAutoCleanup() - запуск автоматической очистки
- stopAutoCleanup() - остановка автоочистки
- updateContextActivity() - обновление времени активности
```

**Конфигурация**:
- **TTL**: 30 минут неактивности
- **Интервал проверки**: каждые 5 минут
- **Автозапуск**: при старте сервера (после восстановления контекстов)

**Результат**:
- ✅ Автоматическое закрытие неактивных контекстов
- ✅ Контролируемое использование памяти
- ✅ Контексты пересоздаются при следующем обращении
- ✅ Логирование процесса очистки

**Файлы изменены**:
- `backend/src/services/browser/browserService.js` - добавлен TTL механизм
- `backend/index.js` - добавлен запуск автоочистки при старте
