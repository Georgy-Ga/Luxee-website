# AI Auto - Обновление задержки между сообщениями

**Дата:** 18.07.2026  
**Файл:** `backend/src/services/aiAuto/index.js`

---

## 📝 Что изменено

Увеличена задержка между отправкой сообщений с **3-6 секунд** на **12-24 секунды**.

---

## 🎯 Причина изменения

Более естественное поведение бота:
- Предыдущие 3-6 секунд выглядели слишком быстро
- Новые 12-24 секунды имитируют реального человека
- Снижается риск обнаружения автоматизации
- Уменьшается нагрузка на Luxee API

---

## 📊 Детали изменения

### **Место 1: Активный профиль (строка 206)**

**Было:**
```javascript
await utils.randomDelay(3000, 6000);
```

**Стало:**
```javascript
await utils.randomDelay(12000, 24000);
```

**Контекст:**  
После успешной отправки сообщения на активном профиле.

## ⏱️ Расчет времени ответа

### Компоненты общего времени:
```
Навигация к чату:       ~3 сек
Извлечение истории:     ~3-5 сек
AI генерация:           ~3-5 сек
Отправка сообщения:     ~1 сек
Задержка (новая):       12-24 сек
────────────────────────────────
ИТОГО:                  22-38 сек
```

### Сценарий: 3 сообщения одновременно

```
10:00:00 - Msg #1, #2, #3 приходят

Msg #1: 
  00:00 - Начало обработки
  00:12 - Готов к отправке
  00:30 - Отправлен (задержка 18 сек)

Msg #2:
  00:35 - Начало обработки  
  00:47 - Готов к отправке
  00:49 - Отправлен (задержка 2 сек, быстрая)

Msg #3:
  00:50 - Начало обработки
  01:02 - Готов к отправке
  01:18 - Отправлен (задержка 16 сек)

ИТОГО: ~78 секунд для 3 сообщений
```

## ✅ Что НЕ изменилось

1. **Mutex система** - глобальная блокировка работает как прежде
2. **Polling интервал** - 5 секунд (проверка каждые 5 сек)
3. **Catch Up логика** - без изменений
4. **Приоритет профилей** - активный профиль первым
5. **Сортировка чатов** - новые первыми

---

## 🔍 Проверка

### Как убедиться что работает:

1. **Проверить логи:**
```
[AI Auto] ✅ Message sent on active profile (Xs)
```

2. **Засечь время между сообщениями:**
   - Должно быть 22-38 секунд между ответами
   - Может быть меньше если сообщения приходят с интервалом

3. **Проверить в Luxee:**
   - Ответы приходят не мгновенно
   - Интервал между ответами естественный

---

## ⚠️ Важные замечания

### Когда задержка НЕ применяется:

1. **При ошибке обработки** - задержки нет, сразу следующий чат
2. **Между попытками в одном цикле** - задержка только после успешной отправки
3. **При account_locked** - цикл вообще пропускается

### Mutex (блокировка):

- Пока идёт обработка одного сообщения - новые циклы пропускаются
- Разблокировка в `finally` блоке - всегда выполняется
- Задержка входит в время блокировки
