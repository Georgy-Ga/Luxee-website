## 🎨 CSS Классы и Паттерны

### Touch-friendly элементы
```css
button, a {
  min-height: 44px;
  min-width: 44px;
}
```

### Адаптивные таблицы
```css
@media (max-width: 1024px) {
  .table-to-cards {
    /* Превращается в карточки */
  }
}
```

### Размеры шрифтов для iOS
```css
input, textarea {
  font-size: 16px; /* Предотвращает zoom */
}
```

### Responsive breakpoints
- **sm**: 640px (мобильные landscape, маленькие планшеты)
- **md**: 768px (планшеты)
- **lg**: 1024px (ноутбуки)
- **xl**: 1280px (desktop)

## 📊 Breakpoints Strategy

### Mobile First подход:
1. **Base (< 640px)**: Максимально простой и вертикальный layout
2. **sm (≥ 640px)**: Начинаем добавлять горизонтальные элементы
3. **md (≥ 768px)**: Планшетный layout
4. **lg (≥ 1024px)**: Полноценный desktop layout
