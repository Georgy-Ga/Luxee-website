## Быстрый старт

### Основные технологии
- **Node.js** v24.14.1+
- **Express.js** v5.2.1 - Web framework
- **MongoDB** + Mongoose v9.4.1 - База данных
- **Playwright** v1.59.1 - Браузерная автоматизация
- **JWT** - Аутентификация
- **Axios** - HTTP клиент для AI API

### Ключевые компоненты
1. **Browser Service** - Управление браузерными контекстами Playwright
2. **Luxee API Services** - Интеграция с Luxee.io через JavaScript API
3. **AI Service** - Генерация ответов через OpenRouter API
4. **Message Check Service** - Автоматическая проверка новых сообщений
5. **AI Management Service** - Управление AI для пользователей и аккаунтов

## Основной поток работы

```
1. Пользователь логинится → JWT токены
2. Добавляет Luxee аккаунт → Браузерная авторизация
3. Система создаёт браузерный контекст → Playwright
4. Каждые 8 секунд проверяет новые сообщения → messageCheckIntervalService
5. При включенном AI → Генерирует и отправляет ответы автоматически
6. Keep-alive каждые 45 секунд → Поддерживает активность
```

## Критические моменты

⚠️ **ВАЖНО**: Система использует JavaScript API Luxee.io (`modelsChat`), который доступен только в браузере. Все операции с чатами выполняются через `page.evaluate()`.

⚠️ **ВАЖНО**: Для каждого Luxee аккаунта создаётся отдельный браузерный контекст, что позволяет работать с несколькими аккаунтами параллельно.

⚠️ **ВАЖНО**: AI работает через отдельный браузерный контекст (`aiContext`), что позволяет AI и пользователю работать параллельно без конфликтов.
