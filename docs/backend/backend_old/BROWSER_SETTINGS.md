# Настройки браузера Playwright

## Конфигурация в .env

```env
# Видимый режим браузера
BROWSER_HEADLESS=false          # false = видимый, true = скрытый

# Замедление действий (в миллисекундах)
BROWSER_SLOW_MO=150            # 0 = без замедления, 100-500 = комфортно для просмотра

# Открывать DevTools автоматически
BROWSER_DEVTOOLS=false         # true = открывать, false = не открывать
```

## Рекомендуемые настройки

### Для разработки (видеть что происходит)
```env
BROWSER_HEADLESS=false
BROWSER_SLOW_MO=150
BROWSER_DEVTOOLS=false
```

### Для отладки (с DevTools)
```env
BROWSER_HEADLESS=false
BROWSER_SLOW_MO=300
BROWSER_DEVTOOLS=true
```

### Для продакшена (быстро и скрытно)
```env
BROWSER_HEADLESS=true
BROWSER_SLOW_MO=0
BROWSER_DEVTOOLS=false
```

## Что делает каждая настройка

### BROWSER_HEADLESS
- **false** (по умолчанию) - Браузер открывается на экране, вы видите все действия
- **true** - Браузер работает в фоне, окно не открывается (быстрее)

### BROWSER_SLOW_MO
- **0** - Действия выполняются мгновенно
- **100-200** - Комфортная скорость для просмотра
- **300-500** - Медленно, для детальной отладки
- Значение в миллисекундах задержки между действиями

### BROWSER_DEVTOOLS
- **false** (по умолчанию) - DevTools не открываются
- **true** - Автоматически открывает Chrome DevTools для отладки

## Дополнительные возможности

Браузер автоматически:
- ✅ Открывается на весь экран (`--start-maximized`)
- ✅ Использует один экземпляр для всех аккаунтов
- ✅ Создаёт изолированные контексты для каждого аккаунта
- ✅ Сохраняет сессии между запусками

## Примеры использования

### Посмотреть как работает авторизация
1. Установите `BROWSER_HEADLESS=false` и `BROWSER_SLOW_MO=200`
2. Запустите тест: `node backend/testRefactored.js`
3. Наблюдайте как браузер автоматически заполняет формы

### Отладить проблему
1. Установите `BROWSER_DEVTOOLS=true` и `BROWSER_SLOW_MO=300`
2. Запустите сервер: `npm run dev --prefix backend`
3. Выполните запрос через API
4. Используйте DevTools для анализа

### Быстрое тестирование
1. Установите `BROWSER_HEADLESS=true` и `BROWSER_SLOW_MO=0`
2. Запустите тесты
3. Браузер работает в фоне максимально быстро
