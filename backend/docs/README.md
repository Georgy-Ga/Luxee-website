## 🚀 Быстрый старт

1. **Установка зависимостей:**
   ```bash
   npm install --prefix backend
   ```

2. **Настройка окружения:**
   - Скопируйте `.env.example` в `.env`
   - Настройте MongoDB и другие параметры

3. **Запуск сервера:**
   ```bash
   npm run dev --prefix backend
   ```

4. **Тестирование:**
   ```bash
   node backend/testRefactored.js
   ```

## 🎯 Основные концепции

### Функциональный подход
Все сервисы реализованы как объекты с функциями, использующими деструктуризацию параметров.

### Один браузер, множество контекстов
Используется один экземпляр браузера Playwright с изолированными контекстами для каждого аккаунта.

### Разделение ответственности
- `browser/` - логика работы с браузером
- `luxeeApi/` - бизнес-логика Luxee
- `controllers/` - обработка HTTP запросов
- `services/` - бизнес-логика приложения

## 📝 Требования

- **MongoDB**: >= 7.1.1

## 💡 Советы

- Используйте `BROWSER_HEADLESS=false` для просмотра работы браузера
- Установите `BROWSER_SLOW_MO=150` чтобы видеть действия
- Включите `BROWSER_DEVTOOLS=true` для отладки
